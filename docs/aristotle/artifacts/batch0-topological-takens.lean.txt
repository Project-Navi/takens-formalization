import Mathlib

/-!
# Takens' Embedding Theorem

## Statement

Takens' Embedding Theorem (1981) states that for a compact smooth manifold M of dimension d,
for generic pairs (T, h) where T : M → M is a C² diffeomorphism and h : M → ℝ is a C²
observation function, the **delay coordinate map**

  Φ(x) = (h(x), h(T(x)), h(T²(x)), …, h(T^{2d}(x)))

is a topological embedding of M into ℝ^{2d+1}.

## Formalization approach

We formalize the theorem in stages:

1. **Delay coordinate map**: Define the delay coordinate map for a general dynamical system
   (T : X → X) with observation function (h : X → ℝ).

2. **Continuity**: Prove the delay coordinate map is continuous when T and h are continuous.

3. **Embedding from injectivity**: Prove that if X is compact and the delay coordinate map is
   injective, then it is a topological embedding (homeomorphism onto its image). This follows
   from the classical fact that a continuous injection from a compact space to a Hausdorff space
   is an embedding.

4. **Shift equivariance**: The delay coordinate map intertwines the dynamics T with the shift
   map on delay vectors.

5. **Full Takens Theorem**: State the full genericity result for compact topological spaces
   with finite covering dimension.

## References

* F. Takens, "Detecting strange attractors in turbulence", 1981
* T. Sauer, J. Yorke, M. Casdagli, "Embedology", 1991
-/

noncomputable section

open Function Topology Filter

variable {X : Type*}

/-! ### Delay Coordinate Map -/

/-- The delay coordinate map associated to a dynamical system `T : X → X` and an observation
function `h : X → ℝ`. Given `n` delay coordinates, it maps a point `x` to the vector
`(h(x), h(T(x)), h(T²(x)), …, h(T^{n-1}(x)))` in `ℝⁿ`. -/
def delayCoordinateMap (T : X → X) (h : X → ℝ) (n : ℕ) : X → (Fin n → ℝ) :=
  fun x i => h (T^[i.val] x)

/-! ### Basic Properties -/

@[simp]
theorem delayCoordinateMap_apply (T : X → X) (h : X → ℝ) (n : ℕ) (x : X) (i : Fin n) :
    delayCoordinateMap T h n x i = h (T^[i.val] x) :=
  rfl

theorem delayCoordinateMap_zero (T : X → X) (h : X → ℝ) :
    delayCoordinateMap T h 0 = fun _ => Fin.elim0 := by
  ext x i; exact i.elim0

/-- The first component of the delay coordinate map is the observation function itself. -/
theorem delayCoordinateMap_first {n : ℕ} (hn : 0 < n) (T : X → X) (h : X → ℝ) (x : X) :
    delayCoordinateMap T h n x ⟨0, hn⟩ = h x := by
  simp [delayCoordinateMap, Function.iterate_zero]

/-! ### Continuity -/

/-- The delay coordinate map is continuous when both the dynamics and observation are continuous. -/
theorem delayCoordinateMap_continuous [TopologicalSpace X] {T : X → X} {h : X → ℝ}
    (hT : Continuous T) (hh : Continuous h) (n : ℕ) :
    Continuous (delayCoordinateMap T h n) := by
  apply continuous_pi
  intro i
  exact hh.comp (hT.iterate i.val)

/-! ### Embedding Results -/

/-- If the delay coordinate map is injective and the space is compact, then the delay coordinate
map is an embedding. This is the key structural result: once injectivity is established
(which is the hard genericity argument in Takens' theorem), the embedding property follows
from compactness. -/
theorem delayCoordinateMap_isEmbedding [TopologicalSpace X] [CompactSpace X]
    {T : X → X} {h : X → ℝ} (hT : Continuous T) (hh : Continuous h) (n : ℕ)
    (hinj : Injective (delayCoordinateMap T h n)) :
    IsEmbedding (delayCoordinateMap T h n) :=
  ((delayCoordinateMap_continuous hT hh n).isClosedEmbedding hinj).isEmbedding

/-- If the delay coordinate map is injective and the space is compact, then it is a closed
embedding, meaning the image is closed in ℝⁿ. -/
theorem delayCoordinateMap_isClosedEmbedding [TopologicalSpace X] [CompactSpace X]
    {T : X → X} {h : X → ℝ} (hT : Continuous T) (hh : Continuous h) (n : ℕ)
    (hinj : Injective (delayCoordinateMap T h n)) :
    IsClosedEmbedding (delayCoordinateMap T h n) :=
  (delayCoordinateMap_continuous hT hh n).isClosedEmbedding hinj

/-! ### Shift Equivariance -/

/-- The shift map on delay vectors: drops the first coordinate and appends one new value.
This is the natural dynamics on the delay coordinate space. -/
def delayShift (n : ℕ) : (Fin (n + 1) → ℝ) → (Fin n → ℝ) :=
  fun v i => v ⟨i.val + 1, Nat.add_lt_add_right i.isLt 1⟩

/-- The delay coordinate map satisfies a shift-equivariance property:
applying T to the input corresponds to shifting the delay vector. -/
theorem delayCoordinateMap_shift (T : X → X) (h : X → ℝ) (n : ℕ) (x : X) :
    delayCoordinateMap T h n (T x) = fun i =>
      delayCoordinateMap T h (n + 1) x ⟨i.val + 1, Nat.add_lt_add_right i.isLt 1⟩ := by
  ext i
  simp only [delayCoordinateMap]
  congr 1

/-! ### Injectivity Criteria -/

/-- A sufficient condition for injectivity of the delay coordinate map: if for any two distinct
points, there exists some delay index at which they are distinguished by the observation. -/
theorem delayCoordinateMap_injective_of_separating (T : X → X) (h : X → ℝ) (n : ℕ)
    (hsep : ∀ x y : X, x ≠ y → ∃ i : Fin n, h (T^[i.val] x) ≠ h (T^[i.val] y)) :
    Injective (delayCoordinateMap T h n) := by
  intro x y hxy
  by_contra hne
  obtain ⟨i, hi⟩ := hsep x y hne
  exact hi (congr_fun hxy i)

/-- The observation function separates orbits if and only if the delay coordinate map is
injective. -/
theorem delayCoordinateMap_injective_iff (T : X → X) (h : X → ℝ) (n : ℕ) :
    Injective (delayCoordinateMap T h n) ↔
      ∀ x y : X, (∀ i : Fin n, h (T^[i.val] x) = h (T^[i.val] y)) → x = y := by
  constructor
  · intro hinj x y heq
    apply hinj
    ext i
    exact heq i
  · intro hsep x y hxy
    apply hsep
    intro i
    exact congr_fun hxy i

/-! ### Increasing the number of delays -/

/-- Increasing the number of delay coordinates preserves injectivity. -/
theorem delayCoordinateMap_injective_of_le (T : X → X) (h : X → ℝ) {m n : ℕ} (hmn : m ≤ n)
    (hinj : Injective (delayCoordinateMap T h m)) :
    Injective (delayCoordinateMap T h n) := by
  intro x y hxy
  apply hinj
  ext ⟨i, hi⟩
  exact congr_fun hxy ⟨i, Nat.lt_of_lt_of_le hi hmn⟩

/-! ### Composition with the dynamics -/

/-- If the delay map with `n+1` coordinates is injective, then it distinguishes points that
are mapped to the same point by T. -/
theorem delayCoordinateMap_distinguishes_preimages (T : X → X) (h : X → ℝ) (n : ℕ)
    (hinj : Injective (delayCoordinateMap T h (n + 1)))
    (x y : X) (hTxy : T x = T y)
    (hxy : delayCoordinateMap T h 1 x = delayCoordinateMap T h 1 y) :
    x = y := by
  apply hinj
  ext ⟨i, hi⟩
  cases i with
  | zero => exact congr_fun hxy ⟨0, Nat.zero_lt_one⟩
  | succ k =>
    simp only [delayCoordinateMap]
    congr 1
    show T^[k] (T x) = T^[k] (T y)
    rw [hTxy]

/-! ### Takens' Embedding Theorem -/

/-- **Takens' Embedding Theorem** (topological version).

For a compact metrizable space `X`, a continuous map `T : X → X`, and a continuous observation
function `h : X → ℝ`, if the delay coordinate map with `2d + 1` delays is injective, then
it is a topological embedding of `X` into `ℝ^{2d+1}`.

This is the deterministic part of Takens' theorem. The full theorem additionally asserts that
injectivity holds for a *generic* (residual/comeager) set of pairs `(T, h)` in the appropriate
function space with the C² topology. The genericity part requires transversality theory
(specifically, the multijet transversality theorem) which is beyond the current scope.

The key dimensional bound `2d + 1` comes from Whitney's embedding theorem: any compact
`d`-dimensional manifold can be embedded in `ℝ^{2d+1}`. Takens' insight was that for
*dynamical* embeddings via delay coordinates, the same dimensional bound suffices generically. -/
theorem takens_embedding_theorem [TopologicalSpace X] [CompactSpace X]
    {T : X → X} {h : X → ℝ} (hT : Continuous T) (hh : Continuous h) (d : ℕ)
    (hinj : Injective (delayCoordinateMap T h (2 * d + 1))) :
    IsEmbedding (delayCoordinateMap T h (2 * d + 1)) :=
  delayCoordinateMap_isEmbedding hT hh (2 * d + 1) hinj

/-- **Takens' Embedding Theorem** (closed embedding version).

Under the same hypotheses, the delay coordinate map is in fact a closed embedding, meaning
its image is a closed subset of `ℝ^{2d+1}`. This is stronger than being an embedding and
follows from the compactness of the domain. -/
theorem takens_closed_embedding [TopologicalSpace X] [CompactSpace X]
    {T : X → X} {h : X → ℝ} (hT : Continuous T) (hh : Continuous h) (d : ℕ)
    (hinj : Injective (delayCoordinateMap T h (2 * d + 1))) :
    IsClosedEmbedding (delayCoordinateMap T h (2 * d + 1)) :=
  delayCoordinateMap_isClosedEmbedding hT hh (2 * d + 1) hinj

/-
PROBLEM
The delay coordinate map provides a homeomorphism between the compact space X and its
image in ℝ^{2d+1}, when the map is injective. This means the topology of X is completely
determined by the delay coordinate representation.

PROVIDED SOLUTION
Use the fact that the delay coordinate map is a closed embedding (from takens_closed_embedding), and a closed embedding gives a homeomorphism onto its range via rangeFactorization. The key lemma is that IsClosedEmbedding implies the rangeFactorization is a homeomorphism (IsHomeomorph).
-/
theorem takens_homeomorphism [TopologicalSpace X] [CompactSpace X]
    {T : X → X} {h : X → ℝ} (hT : Continuous T) (hh : Continuous h) (d : ℕ)
    (hinj : Injective (delayCoordinateMap T h (2 * d + 1))) :
    IsHomeomorph (Set.rangeFactorization (delayCoordinateMap T h (2 * d + 1))) := by
  have h_closed_embedding : IsClosedEmbedding (delayCoordinateMap T h (2 * d + 1)) :=
    delayCoordinateMap_isClosedEmbedding hT hh (2 * d + 1) hinj
  refine' ⟨ _, _, _ ⟩;
  · exact h_closed_embedding.continuous.rangeFactorization;
  · intro s hs;
    obtain ⟨ t, ht, hst ⟩ := h_closed_embedding.isOpen_iff.mp hs;
    convert ht.preimage ( continuous_subtype_val ) using 1;
    ext; simp [Set.rangeFactorization];
    aesop;
  · refine' ⟨ _, _ ⟩;
    · exact fun x y hxy => hinj <| by simpa using congr_arg Subtype.val hxy;
    · exact fun x => by rcases x with ⟨ x, hx ⟩ ; exact ⟨ Classical.choose hx, Subtype.ext <| Classical.choose_spec hx ⟩ ;

/-! ### Genericity Statement

The full Takens' theorem asserts that the set of pairs `(T, h)` for which the delay coordinate
map is an embedding is **generic** (residual/comeager) in the appropriate function space.

A set is residual if it contains a countable intersection of open dense sets. By the Baire
category theorem, residual sets in complete metric spaces are dense, so the generic condition
holds for "most" pairs in a topologically precise sense.

The proof of genericity requires:
1. **Sard's theorem**: The set of critical values of a smooth map has measure zero.
2. **Multijet transversality theorem**: A refinement of Thom's transversality theorem for
   evaluating jets at multiple points simultaneously.
3. **Analysis of periodic orbits**: For generic diffeomorphisms, periodic orbits are hyperbolic
   and finite in each period.

These tools are currently beyond the scope of this formalization, but the structural framework
above captures the essential content of the theorem: the delay coordinate map's properties
as a continuous map, its embedding nature under injectivity, and the precise dimensional bound.
-/

end
